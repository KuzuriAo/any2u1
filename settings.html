Offers

How to offer

Pin the any2u1 button to your toolbar, or you won't see the number: the browser hides it on an unpinned extension. Clicking the button opens the small window. After a download, the browser's own download panel can open over that part of the toolbar and cover the number until it closes.

A download manager that takes over your downloads hides them from the browser, so there's no offer for them. The same goes if a saved file has a random name or no .3mf ending. For any saved file, click the toolbar button and choose it.

Saving

The browser's Save dialog opens for each file, so you can rename it or choose another folder. A zip of several 3MF files opens one dialog per file. Off, each file is saved next to your other downloads as <name>_U1.3mf.

    Hosts you gave access to

    The extension uses these only to fetch a file you chose to convert. Some browsers remember an approval, so a host you remove can come back without a new prompt until the extension is removed.

      A CORS error in the browser's logs

      When you convert a download, any2u1 first tries to read the file without asking for any site access. If the site doesn't allow that, the browser logs a red error saying the request was blocked by a CORS policy. You can see it in the developer console, and in the extension's list of errors if you have Developer mode turned on. That is expected and nothing is wrong. any2u1 logs a warning beside it that says so. any2u1 then offers two choices: allow access to that one site, or choose the file you saved. Nothing is sent anywhere.
