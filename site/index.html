any2u1
PrivacySource

Download a model the way you always do. Get a Snapmaker U1 file.

any2u1 is a browser extension. When a 3MF project finishes downloading, it offers to convert it for the Snapmaker U1, and does it on your device. Nothing is uploaded.

It reads projects saved by Bambu Studio, Creality Print, Anycubic Slicer Next, ElegooSlicer, Flash Studio, PrusaSlicer and QIDI Studio, on any site that offers a 3MF download.

How it works

  1. A 3MF finishes downloading, and a small window asks whether to convert it.
  2. You click Convert for Snapmaker U1. If the site's server allows it, the extension fetches the file again, with no prompt. If it doesn't, the extension explains and lets you choose: allow access to that one host, or pick the copy you saved. A file the site built in the page goes straight to picking the saved copy.
  3. The converted file, named <name>_U1.3mf, is saved next to your other downloads, with any notes worth reading and a button to show it in its folder.
In Snapmaker Orca, choose Open as project, or open the file from an empty plate. "Import geometry only" drops the printer, filament and process settings.

You can also click the toolbar button and drop a 3MF, or a zip of 3MF files, on the page at any time. If you'd rather have no window, a setting shows a number on the toolbar button instead, and you can turn offers off, or off for one site.

Options

  • Snapmaker Orca version: pick the one you run. The newest is the default, and the extension tells you when an update adds one.
  • High-flow toolheads: mark each toolhead with the Liber High Flow Hotend.
  • Hardened steel nozzles, so Snapmaker Orca warns about abrasive filaments correctly.
  • Filament names for Snapmaker Space, which accepts a file only if every filament name starts with Snapmaker or Generic. Only names change, never temperatures or flow.

What it asks for

PermissionWhy
DownloadsTo see that a 3MF finished downloading, save the converted file, and show it in its folder.
StorageTo remember your settings.
One host, only if you allow itTo fetch a file you chose to convert, when that host's server won't otherwise let an extension read it. It never asks for all sites, and it doesn't read the pages you visit.

Install

any2u1 isn't in the extension stores yet. Until it is, you can build it from its source and load it yourself; the README has the steps.

Built on any2orca

The conversion itself is the any2orca library, which I also maintain. The extension's tests check that each file it saves is byte-for-byte what the library makes from the same file and options.
