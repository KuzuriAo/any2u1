Privacy policy

Short version: your files are converted on your device and never leave it. I collect nothing.

This covers the any2u1 browser extension, version 0.1.0 and later. Last updated November 4, 2026.

What it handles

Everything here stays on your device, with one exception: the plain request, described below, that fetches the file you chose to convert.

The one request

Besides loading its own files, the extension makes one kind of request, and only when you click to convert a download: it fetches that one file again, from the address your browser downloaded it from. It sends no cookies and no referrer with it. It doesn't fetch anything else, and it doesn't contact me or anyone else. It has no analytics, telemetry, advertising or accounts.

A failure report

When a conversion fails, the page offers a report you can copy. It holds the error's code, the browser and its major version, the site's name if the download came from one, the file's size in bytes, and the versions of the extension and the library. It holds no file name, no address, and no error text, since any of them can identify a model. You can read the report on screen before you copy it.

Site access you allow

If a site's server won't let the extension read a file, the extension can ask your permission for that one host. It uses that access only to fetch a file you chose to convert. The extension's settings page lists every host you allowed, and removes one. Some browsers remember an approval until the extension is removed.

What it doesn't do

It doesn't read or change the pages you visit, it doesn't track what you browse, and it doesn't sell or share data, because it has none to share.

Changes and contact

If this policy changes, the new version will be posted here with a new date. Questions go to the project's issue tracker.
