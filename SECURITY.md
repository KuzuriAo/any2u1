# Security

If you find a security problem in any2u1, please report it privately, not in a public issue: email support@kuzuriao.com.

Say what you found, which browser and version, and how to reproduce it. A file that shows the problem helps, but only send one you're free to share. I'll reply as soon as I can, and I'll credit you in the release that fixes it if you'd like.

any2u1 converts files with the any2orca library. A problem in the conversion itself belongs to [any2orca's security policy](https://github.com/KuzuriAo/any2orca/security/policy); if you're not sure which it is, send it here.
